# Playwright POM Automation

A Playwright + Cucumber test automation project using Page Object Model, MySQL validation, API testing, and JSON-based test data.

## Project Overview

This repository includes:

- `featureFiles/` - Gherkin feature files
- `stepDefinitions/` - Cucumber step implementations
- `methods/` - Page Object Model classes for UI interactions
- `hooks/` - Cucumber hooks for setup and teardown
- `utils/` - helpers for API, DB, JSON, and other utilities
- `testData/` - JSON test data files
- `postman/` - Postman collection for API testing
- `reports/`, `test-results/` - generated test reports

## Folder Structure

```text
featureFiles/      # Gherkin feature files
stepDefinitions/   # Step definition code
methods/           # Page Object Model classes
hooks/             # Cucumber setup/teardown hooks
utils/             # API, DB and JSON helpers
testData/          # JSON test data files
postman/           # Postman collection files
reports/           # Report output folder
test-results/      # Playwright output folder
```

## Setup

1. Install dependencies:

```bash
npm install
```

2. Install Playwright browsers:

```bash
npx playwright install
```

3. Create a `.env` file in the project root:

```env
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3307
MYSQL_USER=your_mysql_user
MYSQL_PASSWORD=your_mysql_password
MYSQL_DATABASE=qa_automation
```

4. Make sure the database exists or create it manually:

```sql
CREATE DATABASE IF NOT EXISTS qa_automation;
```

## Run Tests

```bash
npm test
```

## Run Postman Collection

```bash
npm run postman:run
```

## Allure Report

This project is configured to generate Allure reports using Cucumber + Allure integration.

1. Run the tests:

```bash
npm test
```

2. Generate the report:

```bash
npm run allure:generate
```

3. Open the report:

```bash
npm run allure:open
```

> Note: Allure requires Java installed and `JAVA_HOME` set correctly on your machine.

If your environment does not have Java, you can still use the `reports/cucumber-report.html` generated by Cucumber.

## GitHub Preparation

To publish this project on GitHub:

1. Initialize git:

```bash
git init
```

2. Add files and commit:

```bash
git add .
git commit -m "Initial Playwright POM automation setup"
```

3. Add remote and push:

```bash
git branch -M main
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
```

4. Enable GitHub Actions and check the workflow status in the repository.

## GitHub Actions

A CI workflow is included at `.github/workflows/ci.yml` to:

- install dependencies
- install Playwright browsers
- create the test database
- run `npx tsc --noEmit`
- run `npm test`

## Notes

- Keep `testData/` clean and maintain reusable JSON files for stable test data.
- Use descriptive branch names like `feature/login-tests` or `fix/db-validation`.
- Push small, frequent commits with clear messages.
